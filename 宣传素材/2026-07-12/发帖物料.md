## 一、封面图

### 首选（推荐）

| 项目 | 说明 |
|------|------|
| **截帧位置** | 第 23 关，**T≈14.6～16.6s**（第 2 次重开后停 2s）或 **T≈35.8s**（蓝元件卡住） |
| **画面要素** | 棋盘上有 **红/蓝滤色元件** + **黄/紫等多色靶** + 光路明显 **没全亮** |
| **情绪** | 「卡住了 / 咋过」— 让人想点进去看解法 |
| **比例** | **3:4 竖图**（抖音/小红书封面）；可从 9:16 成片居中裁切 |

### 备选

| 方案 | 截帧 | 适用 |
|------|------|------|
| B | 第 2 次 **点重开** 瞬间（T≈14.5s） | 强调「又错了/又重来」试错感 |
| C | 回 **Menu 定格**（T≈40.8s） | 带游戏名，偏品牌向 |

### 封面上大字（二选一）

**方案 A（挑衅，推荐）**

```
第23关

```

**方案 B（机制向）**

```

```

### 封面排版（剪映 / 醒图）

| 元素 | 建议 |
|------|------|
| **主标题** | 白字 + **黑色描边 4～6px**，或黄字 `#FFE566` + 黑描边 |
| **字号** | 占画面宽 **60～70%**，两行居中略偏上（留出棋盘） |
| **副标（小字）** | 底栏：`小咪的光学迷宫` 或 `推箱子·光学解谜`，字号为主标题 1/3 |
| **避免** | 挡住光源、挡住「卡住」的红/蓝元件（那是视觉钩子） |
| **滤镜** | 封面可 **+5～10% 对比度、+5% 饱和度**，让光路更显眼 |

### 封面制作步骤

1. 成片导入剪映 → 拖到 **T=15s** 或 **T=36s** → **导出帧** 为图片  
2. 新建 **3:4** 画布，贴截图（放大棋盘区域）  
3. 加主标题「第23关 / 咋过啊？」  
4. 底栏小字「小咪的光学迷宫」  
5. 导出 **1080×1440** 作发布封面
