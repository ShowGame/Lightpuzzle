# 录屏自动回放说明

> 按预设脚本自动走关，带完整 Q 弹滑格、光路、音效。  
> **发版前务必关闭** `RECORD_REPLAY_ENABLED`。

---

## 快速开始

1. 编辑 `assets/Scripts/Config/OpticalRecordReplayConfig.ts`  
   - `RECORD_REPLAY_ENABLED = true`  
   - `RECORD_REPLAY_ACTIVE_SCRIPT = 'viral_challenge_02_25'`（见 [发布日历](../总规划/发布日历.md) 三条爆款脚本）
2. 运行 Game 场景，开系统录屏
3. 录完改回 `RECORD_REPLAY_ENABLED = false`

---

## 字段说明

| 字段 | 含义 |
|------|------|
| `levelId` | 关卡编号 |
| `moves` | 可选；省略用 `bestSolution` |
| `maxSteps` | 最多演示几步，**不必通关** |
| `holdBeforeSec` | 开局停留 |
| `holdAfterSec` | 段末停留 |
| `stepIntervalSec` | 每步间隔 |

方向：`w` 上 / `a` 左 / `s` 下 / `d` 右

---

## 快捷键（PC 预览）

| 键 | 作用 |
|----|------|
| P | 暂停/继续 |
| R | 重播当前段 |
| N | 下一段 |
