**光路变化规律（口播/字幕用）：**

- 每推一步 **可动光学元件**（数字 `1`～`4`）→ 光束路径实时重算  
- `1` 转角 / `2` 直通 / **`3` T 型分光** / `4` 十字  
- **颜色**：`W` 白 → 经 `R/G/B` 滤色片染色 → 目标格须 **同色** 才点亮（第 8 关起）  
- **二次色**（第 17 关起密集）：`Y` 黄 / `C` 青 / `P` 紫 — 常需 **混光** 才能命中目标  
- 推错：光打墙、色差、只亮一个目标 → 接收器保持暗色（**非死局**，可 **撤回 5 步**）

### 第 17 关 · 关卡拆解（9 步，口播/走错依据）

| 要素 | 配置 |
|------|------|
| 棋盘 | 7×6，右上收口，视觉紧凑 |
| 光源 | `S` 白光，朝右下 |
| 目标 | `E` = **紫色 `P`**（二次色，不是单色红/蓝能打亮） |
| 元件 | 两枚 `1` 转角：一枚 **蓝滤 `B`**、一枚 **红滤 `R`** |
| 正解 | `d w a w a s d s a`（9 步） |
| 录屏价值 | **颜色混错一眼假**：只红或只蓝打到紫靶 → 不亮 |

**建议走错（手操 4 步）**：`d → w → s → d`（第 3 步用 `s` 代替正解 `a`）  
→ 红/蓝路径对不上紫目标，全场仍暗，口播：「紫色目标，单色光根本点不亮」。

### 第 25 关 · 关卡拆解（11 步，口播/走错依据）

| 要素 | 配置 |
|------|------|
| 棋盘 | 9×7，上下分区，**中后期代表关** |
| 光源 | **双光源 `SS`**，均为红光 |
| 目标 | 上路 **黄 `Y`** + 下路 **黄 `Y` + 紫 `P`**（三个接收器） |
| 元件 | **`3` T 分光** + **`2` 直通**；旁侧 **G/B 滤色** |
| 正解 | `s a s d a a a w d d s`（11 步） |
| 录屏价值 | **两束红光、一分二、混出黄/紫** — 光路变化比第 9 关更满、更「像大作」 |

**建议走错（手操 4 步）**：`s → a → s → w`（第 4 步用 `w` 代替正解 `d`）  
→ T 型分光器错位，**只亮一个靶或全暗**，口播：「双光源还要分三路颜色，推错全废」。

## 二、录制通用设置

```typescript
// assets/Scripts/Config/OpticalRecordReplayConfig.ts
RECORD_REPLAY_ENABLED = true
RECORD_REPLAY_HIDE_HUD = true          // 录完可在剪辑里叠字幕
RECORD_REPLAY_SKIP_SAVE_AND_WIN_UI = true
```

| 项目 | 建议 |
|------|------|
| **简单关** | 用自动回放 `moves` / `bestSolution` 全通，保证 2～3 步利落 |
| **难关走错** | **建议手操** 3～5 步（自动回放不易「故意走歪」） |
| **撤回演示** | 走错后点 **撤回** 1～2 次，再手操或回放正确几步（脚本 C 必拍） |
| **返回 Menu** | 局内点 **TopBar → BtnBackMenu**（`GameUIManager.backToMenu`） |
| **定格画面** | Menu 主界面 **GameTitle 图标 +「光学迷宫」** 停 2～3 秒 |
| **时长目标** | **28～34 秒**（对齐抖音/小红书爆款） |

## 脚本 A · 挑衅挑战向（**推荐首发 · 第 25 关**）

**定位**：抖音主投；「前几关简单，**第 25 关呢？**」反差 + 左下角 CTA  
**简单关**：**第 2 关**（2 步全通，建立「这么简单么」）  
**难关**：**第 25 关**（双光源 + 分光 + 黄/紫目标，**11 步**）

### 录屏设计

| 时段 | 关卡 | 操作 | 画面要点 |
|------|------|------|----------|
| 0～1.2s | 2 | 开局定格 | 光未通 |
| 1.2～4s | 2 | 自动：`s` `a` 全通 | Q 弹 + 溅射 |
| 4～6s | — | 字幕 | **「小游戏这么简单吗？」** |
| 6～8s | 25 | 切关字幕 | **「第 25 关呢？」** 展示双 `SS` 光源 |
| 8～20s | 25 | **手操走错** `s a s w` | T 分光错位，多靶全暗/只亮一个 |
| 20～24s | 25 | 撤回 ×2 → 回放前 6 步 | 红光分束、黄/紫路逐渐亮起 |
| 24～30s | Menu | 返回主界面 | **光学迷宫** +「共 50 关」 |

**口播全文（约 30 秒）**

> 别笑，前两关谁都会。  
> **就这？小游戏这么简单吗？**  
> **第 25 关：双光源、还要分光、还要混出黄色和紫色。**  
> 推错一下，三个靶子一个都不亮。  
> 左下角直接玩｜搜「小咪的光学迷宫」——**五十关，后面更烧脑。**

**发布标题**：前两关简单？第 25 关你试试｜双光源光学推箱子  
**回放**：`viral_challenge_02_25`

## 脚本 B · 推错全废向（**第 17 关 · 紫色目标**）

**定位**：抖音 + 小红书；强调 **二次色 / 混光** 门槛

**难关**：**第 17 关**（紫目标 `P`，9 步，棋盘紧凑好取景）

### 录屏设计

| 时段 | 关卡 | 操作 | 画面要点 |
|------|------|------|----------|
| 0～4s | 2 | 自动全通 | 快节奏上手 |
| 4～6s | — | | **「这么简单吗？」** |

| 18～22s | 17 | 重置/撤回 → 回放前 5 步 | `d w a w a` 光色开始对了 |

**口播全文**

**发布标题**：紫色目标怎么点亮？｜第 17 关推箱子光学｜共 50 关

**前期关备选回放**（仍保留）：`viral_challenge_02_09` / `viral_wrong_light_01_04` / `viral_undo_color_02_08`
