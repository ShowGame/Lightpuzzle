## 1. 要不要新开号？（结论）

| 账号 | 用途 |
|------|------|
| **个人号（原有）** | 生活、开发碎碎念、偶尔转发游戏一条；**不作为主投放** |
| **工作室专号（新建）** | **只发**旗下小游戏实机与开发日常；当前主推《小咪的光学迷宫》，后续可发《速记大师》及新作，**账号名不绑单款游戏** |

个人号与游戏号 **分工**，避免抖音/小红书给账号打「杂标签」，导致游戏视频推不准。

## 2. 开哪几个平台？（按优先级）

独立开发者时间有限，建议 **先 2 个主阵地 + 2 个同步**，不要一上来全平台。

| 优先级 | 平台 | 是否必开 | 作用 | 养号强度 |
|--------|------|----------|------|----------|
| **P0** | **抖音** | ✅ 必开 | 小游戏挂载、自然流量最大、你已有爆款调研 | 中（3～7 天） |
| **P0** | **微信游戏圈** | ✅ 用游戏自带 | 已在玩的人、留存与互动；**不是自媒体号** | 无养号，直接发帖 |
| **P1** | **小红书** | ✅ 建议开 | 图文+短视频，「摸鱼益智」搜索长尾 | 中（3～7 天） |
| **P1** | **微信视频号** | ✅ 建议开 | 同步抖音成片，触达 30+、微信熟人链 | 低（同步即可） |
| **P2** | **B 站** | 可选 | 开发日志、8～15 分钟长视频，第 2 周再开 | 低 |
| **P3** | 知乎 / V2EX / indienova | 可选 | 长尾品牌、开发者故事，**不用养号** | 无 |

**第一周只做：抖音游戏号 + 小红书游戏号 + 游戏圈 + 视频号同步。**

## 3. 注册与账号设置（一次性清单）

### 3.1 用什么注册？

| 问题 | 建议 |
|------|------|
| 要不要新手机号？ | **不必须**。同一手机号可登多个号（抖音/小红书均支持多账号切换，以 App 当前规则为准） |
| 要不要新手机？ | **不必须**。养号阶段注意 **同一 WiFi 下不要一机登 10 个号** 即可 |
| 实名认证 | **要**。抖音挂载小游戏、提现、提高权重通常需实名；用你自己或工作室法人 |

### 3.1.1 WiFi 还是流量？要不要隔离网络？

| 你的情况 | 建议 |
|----------|------|
| **1 个游戏新号 + 个人号**（本指南默认） | **WiFi / 流量都行**，不必隔离、不必只开流量 |
| 同一手机切换抖音/小红书 **2～3 个号** | 仍然 **一般没问题**，正常用即可 |
| **多机多号矩阵**（5 个以上新号同天注册、同设备养） | 才需要考虑：不同设备、不同网络、降低关联风险 |

**说明：**「养号要用流量、WiFi 会限流」多半来自 **批量起号/矩阵运营** 话术。独立开发者单号推广，平台看的是 **内容是否垂直、是否像营销号**，不是你家宽带 IP。

**实操建议：**

- 日常用手机 **哪个网顺手用哪个**（家里 WiFi、公司 WiFi、4G/5G 均可）  
- **避免**：同一台手机短时间内注册/登录 **大量** 新号并互相关注互刷  
- **不必**：为了养号专门买流量卡、专门隔离路由器、一机一号一 IP  

个人号与游戏号 **可以同 WiFi、同手机切换**；内容和人设分开比网络分开重要得多。

### 3.1.2 已有抖音小号：注销重开，还是改资料？

| 情况 | 建议 |
|------|------|
| **小号几乎没发过 / 发过几条无关内容** | ✅ **不用注销**。一次性改昵称、头像、简介（§3.2），然后按 §5 养号 3～7 天 |
| **小号发过不少杂内容（生活、带货等）** | ✅ 仍建议 **先改资料 + 养号**；旧视频 **隐藏或删除** 明显无关的，留 0～2 条也行 |
| **小号曾被限流、封禁、违规警告** | ⚠️ 改资料难救，考虑 **注销重开** 或换一个新号 |
| **想「从零开始」但号很干净** | 注销 **不是必须**；干净旧号往往比全新号多一点点权重 |

**推荐流程（你的情况大概率走这条）：**

1. 昵称改为 **秀幹工作室**，头像、简介按 §3.2 一次改齐（**不要三天两头再改**）  
2. 把旧作品里 **和游戏完全无关的** 设为私密或删掉  
3. **不要立刻发** 07-12 成片；先按 §4.3 搜 `推箱子小游戏` 等刷 3 天  
4. Day 7 再首发长片  

**不必注销的原因：** 抖音看的是 **近期浏览/互动/发文垂类**，养号几天会把标签拉回来；注销还要等冷却、重绑手机号，得不偿失。

### 3.2 统一人设（全平台 · 已定稿）

> **账号定位**：工作室品牌号，不绑单款游戏；视频标题/口播可写当前主推作（如《小咪的光学迷宫》），**主页昵称与简介保持工作室层级**。

| 字段 | 定稿 |
|------|------|
| **昵称** | **秀幹工作室**（全平台一致，含抖音 / 小红书 / 视频号 / B 站） |
| **头像** | 工作室字标「秀幹」或中性 Logo（**勿**长期用单款游戏主角，方便后续换主推作） |
| **背景图** | 当前主推作截图即可（如第 23 关多色光路）；换游戏时只换背景，昵称简介不动 |
| **领域/标签** | 游戏 · 益智 · 独立开发 / 小游戏 |

## 4. 养号是什么？（针对工作室游戏垂直号）

**养号** = 新号前几天让平台识别「你是做游戏/益智内容的」，避免第一条就被当营销号限流。

### 4.1 原则（2026 年仍适用）

1. **垂直**：只看、只赞、只评 **益智/小游戏/解谜/独立游戏** 内容（不限于推箱子光学）
2. **像真人**：每天刷 15～30 分钟，分 2 次，别 10 分钟狂点 100 个赞  
3. **别硬广**：养号期不发「下载链接刷屏」；**游戏实机过程** 从第 4 天起可发  
4. **稳定**：昵称、头像、简介 **上线后不要三天两头改**

### 4.2 不必迷信「14 天不能发作品」

游戏实机号如果 **第一条就是高质量竖屏玩法**（你 07-12 成片），很多案例 **第 3～4 天** 就可发第一条测试。  
保守做法：**养 3 天 → 发 1 条 → 再养 2 天 → 首发 07-12 成片**。

### 4.3 养号搜什么？（搜索词 + 关注谁）

养号期 **只搜、只刷、只互动** 下面这类内容，让平台给你打上「益智小游戏 / 独立游戏」标签。

#### 抖音（优先搜这些）

| 优先级 | 搜索词 | 说明 |
|--------|--------|------|
| **P0** | `推箱子小游戏` | 最贴你玩法，调研里 30 万赞赛道 |
| **P0** | `推箱子经典版` | 成熟流量词，学实机节奏与标签 |
| **P0** | `益智小游戏` | 垂类大盘，完播 5 条即可 |
| **P1** | `抖音小游戏` | 学挂载、标题、口播转化 |
| **P1** | `解谜游戏` `烧脑游戏` | 扩标签，别只盯推箱子 |
| **P1** | `微信小游戏` | 与你上架渠道一致 |
| **P2** | `独立游戏开发` | 偶尔刷，为以后发开发日常留标签 |
| **P2** | `光学解谜` `推箱子解谜` | 量可能少，搜到就多看 |

**Day 1～2 每天搜 3～4 个 P0/P1 词即可**，每个词 **完播 2～3 条** 再划走，别秒划。

#### 建议直接关注的对标账号（抖音）

从 [爆款脚本调研备忘.md](./爆款脚本调研备忘.md) 提炼，养号期 **关注 10～20 个** 即可：

| 账号 | 可参考点 |
|------|----------|

#### 每天怎么搜（15～20 分钟）

1. 打开 App → 搜索 **1 个 P0 词** → 点「视频」/「全部」  
2. **完播** 3～5 条（每条至少 15s，最好看完）  
3. **点赞** 2～3、**评论** 0～1（短评：`这关我也卡过` `推错一步全废`）  
4. 再搜 **1 个 P1 词**，重复；**不要**连续狂赞 20 条  
5. 从推荐页若刷到 **美女/时政/带货**，立刻划走别停留  

#### 养号期别搜这些

| ❌ 别搜 | 原因 |
|---------|------|
| 你的游戏全名当主搜词 | 没内容量，标签打不准；首发后再搜自己 |
| `游戏推广` `买量` `起号` | 平台当你营销号 |
| 无关热门（八卦、颜值、带货） | 标签跑偏 |
| 竞品名辱骂/拉踩 | 无意义且伤号 |

## 5. 七天养号 SOP（秀幹工作室专号）

> 以下 **Day 1 = 你注册并完善资料当天**。个人号可照常使用，**不要**用个人号做养号刷屏。

### Day 1｜建号 + 画像

- [ ] 注册抖音、小红书 **工作室专号**（视频号可 Day 3 再开）  
- [ ] 填齐昵称 **秀幹工作室** / 头像 / 简介（§3.2，用工作室文案，勿写单款游戏名）
- [ ] 抖音：搜索 `推箱子小游戏` 或 `益智小游戏`，关注 10～20 个对标账号（§4.3 表）  
- [ ] 小红书：搜索 `解压小游戏` 或 `推箱子重温`，同样关注 10～20 个

- [ ] **不发作品**

### Day 2｜加深标签

- [ ] 早/晚各刷 15 分钟，继续只看游戏垂类  
- [ ] 按 §4.3 **换 3～4 个搜索词**各刷几条（如：`推箱子小游戏` `益智小游戏` `解压小游戏` `抖音小游戏`）
- [ ] 评论 2 条高赞视频（增加账号活跃）  
- [ ] 不发作品；可用小号或朋友号 **浏览工作室专号主页** 一次（极轻量）

### Day 3｜试探首发（可选）

- [ ] 发 **1 条极短测试**（5～10s）：第 2 关 Q 弹推一下，**无挂载硬广**，标题：`推一下光就拐弯`  
- [ ] 继续刷 15 分钟同类内容  
- [ ] 视频号：开通并 **隐藏同步** 或发 1 条同款测试

### Day 4～5｜继续垂直 + 备片

- [ ] 每日刷 15 分钟 + 评 1 条  
- [ ] 录好 / 剪好 **07-12 成片**（见 `宣传素材/2026-07-12/`）  
- [ ] 按 [发帖物料.md](../2026-07-12/发帖物料.md) 做好封面 3:4  
- [ ] **仍不发长片**，除非 Day 3 测试播放 > 200（说明标签开始对了）

### Day 6｜首发彩排

- [ ] 抖音创作者中心检查：**小游戏挂载**是否可用（若未过审，首条片尾口播「微信搜小咪的光学迷宫」）  
- [ ] 定时或准备好 Day 7 发布时间（建议 **12:00 或 20:30**）  
- [ ] 游戏圈写好首发帖（不必养号）

### Day 7｜正式首发

- [ ] **抖音游戏号** 发 07-12 成片 + [发帖物料](../2026-07-12/发帖物料.md) 标题/描述/封面

- [ ] **视频号** 同步一条  
- [ ] **游戏圈** 发求助/介绍帖  
- [ ] 个人号 **只转发或置顶一条**，不重复日更

## 6. 发布后怎么「养」（养权重，不是养号）

首发之后 **前 14 天** 比养号更重要：

| 动作 | 频率 | 说明 |
|------|------|------|
| 发视频 | **≥ 5 条/周** | 07-12 / 07-13 / 07-14 三条爆款 + 2 条库存 |
| 回复评论 | **发片后 2 小时内** 必回前 10 条 | 算法友好 |
| 自评抢沙发 | 每条 1 条 | 「第 23 关卡住的举手」 |
| 继续刷垂类 | 10 分钟/天 | 维持账号活跃 |
| 不删稿 | 播放差也别删 | 保持主页内容统一 |

**内容类型比例（工作室专号）：**

- 70% 实机卡关 / 挑衅 / 通关爽感（你现有脚本）  
- 20% 轻教学（混色、分光一条讲清）  
- 10% 开发者碎碎念（建立信任，可放 B 站）

## 7. 各平台发什么？（和养号后的正片分工）

| 平台 | 发什么 | 不发什么 |
|------|--------|----------|
| **抖音** | 15～45s 竖屏实机、挂载/口播 CTA | 长开发日志、纯文字 |

## 9. 养号禁忌（踩了容易限流）

| ❌ 不要做 | ✅ 改为 |

## 11. 数据盯什么（新号）

养号阶段 **别看播放量焦虑**，看：

| 指标 | 健康信号 |
|------|----------|
| 首发 24h 播放 | > 300 说明标签开始对了 |
| 完播率 | > 30% 可加码投同类选题 |
| 进游戏点击 | 挂载/口播后有人搜游戏名 |
| 涨粉 | 首周 50+ 垂直粉就合格 |

每周填表（可放 Notion/飞书）：日期、发布条数、最高播放、新增粉、游戏新增玩家。
