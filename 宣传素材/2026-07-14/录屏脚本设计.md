# 录屏脚本设计 · 脚本 C · viral_undo_color_03_25

> 对应发布日：2026-07-14  
> 代码：`assets/Scripts/Config/OpticalRecordReplayConfig.ts`

## 定位

差异化深度向：第 3 关全通 → 铺垫「50 关」→ **第 25 关**走错 + **撤回** → 正解 8 步演示 → 返回 Menu。

## 分段

| 段 | 关 | 模式 | 操作 | 备注 |
|----|-----|------|------|------|
| 1 | 3 | 自动通关 | 4 步全通 | 有墙隔断，避免「太托儿」 |
| 2 | 25 | **手操走错 + 撤回** | 走错若干步 → 撤回 ×3 | 可短暂显示 HUD 撤回钮 |
| 3 | 25 | 回放 | 正解前 8 步 | `s a s d a a a w` |
| 4 | Menu | 手操 | 点 TopBar 返回 | 字幕：50 关 · 能撤回 · 无死局逼广告 |

## 录制

```typescript
RECORD_REPLAY_ENABLED = true
RECORD_REPLAY_HIDE_HUD = true          // 走错段可临时关，展示撤回钮
RECORD_REPLAY_SKIP_SAVE_AND_WIN_UI = true
RECORD_REPLAY_ACTIVE_SCRIPT = 'viral_undo_color_03_25'
```

## 关卡要点（第 25 关）

- 双红光 `SS` + T 分光 `3` + 直通 `2`
- 目标：黄 `Y` / 黄 `Y` / 紫 `P`
- 正解 11 步，本脚本演示前 8 步即可
- 卖点：**撤回 5 步** + **无死局逼广告** + **共 50 关**
