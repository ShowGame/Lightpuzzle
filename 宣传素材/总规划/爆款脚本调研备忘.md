## 0. 平台能力 & 抖音要不要装什么？

| 平台 | 要不要额外安装 | 现状 | 搜爆款视频命令 |
|------|----------------|------|----------------|
| **小红书** | ❌ 不用 | ✅ 已登录，OpenCLI 可用 | `opencli xiaohongshu search "解压视频 小游戏" -f yaml` |
| **抖音** | ❌ 不用新装包 | ✅ **已登录**（秀幹） | `opencli douyin search "推箱子小游戏" --limit 20 -f yaml` |
| B站（参考） | ❌ 不用 | ✅ OpenCLI 可用 | `opencli bilibili search "抖音小游戏" -f yaml` |

**抖音你只需要做一件事**（和装小红书时一样）：

1. Chrome 打开 [www.douyin.com](https://www.douyin.com) 或 [creator.douyin.com](https://creator.douyin.com) 并**登录**
2. 验证：`opencli douyin whoami -f yaml` 显示 `logged_in: true`
3. 搜视频：`opencli douyin search "益智小游戏" -f yaml`  
   → 返回字段含 **plays / likes / comments / shares**，比小红书更适合比「播放量级」爆款

> agent-reach **没有**单独的「抖音 channel 安装包」；抖音能力已内置在 **OpenCLI**（你已装好 v1.8.6 + Chrome 扩展）。

### C. 抖音视频 vs 小红书（你做视频的差异）

| 维度 | 抖音爆款 | 小红书爆款 |
|------|----------|------------|
| **必备标签** | `#抖音小游戏` + 游戏名/类型 | `#解压视频` `#游戏实况` |
| **挂载话术** | 「左下角点击即玩」「无需下载」 | 「微信搜 xxx」 |
| **标题风格** | 更短、更挑衅（麦克阿瑟/怎么过啊/这都能…） | 更体感/身份（脑子光滑/牛马专享） |
| **推箱子爆款** | `#推箱子经典版` 是成熟流量词 | `#推箱子重温` 怀旧向 |
| **时长体感** | 实机过关/卡关一瞬间 | 可略长、可动画 |

## 2. 高赞帖正文结构提炼

### ① 标题公式（来自 ≥1000 赞样本）

```
[夸张体感/身份] + [游戏或结果]
[互动挑战] + [治愈/搞笑对象]
[情绪结果] + [游戏名/类型]
[求安利] + [痛点一句]
```

**实测高赞标题原句：**

- 「玩了这游戏感觉**脑子都变光滑了**！」→ 夸张体感，无玩法解释
- 「今天又是**牛马专享**」→ 打工人身份，无游戏名
- 「请找出鸭子中**唯一的一只小鸡**」→ 挑战句 + 具体任务
- 「**上头了玩一晚上**凶案数独」→ 情绪结果 + 游戏名
- 「想玩点**小游戏**」→ 极简需求（收藏 2014）
- 「小时候**不懂**的游戏」→ 怀旧悬念（推箱子标签）

### ② 正文 / 视频节奏（小红书有效，可映射到抖音 21～34 秒）

| 类型 | 代表帖 | 结构 |
|------|--------|------|
| **解压实机** | 脑子变光滑（1.6万） | 标题夸张 → 直接游戏名 → 实况画面说话少 |
| **怀旧推箱子** | 小时候不懂的游戏（5175） | #解压视频 + #推箱子重温，画面优先 |
| **互动谜题** | 找小鸡（6509） | 一张图/一段视频 + 「来找」→ 评论区狂欢 |
| **体验长文** | 凶案数独（2717） | 摸鱼开场 → 难度递进 → 通宵结果 → 攻略建议 |
| **求安利** | 想玩点小游戏（2586） | **先说讨厌什么**（死局逼广告）→ 再说要什么 → 标签 |
| **开发者数据** | 50天收益（1179） | 数字清单 + 开放提问（买量能不能盈利） |

### 3.7 数独/推理深度玩家（2717 赞帖）

- 「有没有**类似**这种的小游戏」→ 通关后**求同类**是强需求
- 「太好玩了两天全通已经**买书了**」→ 深度内容可导向**实体/付费**
- 吐槽攻略/存档问题 → 硬核玩家在意**可重置、不串档**

**→ 07-16 烧脑向：结尾用「通关来评论区晒步数」比「感谢关注」更贴这类受众。**
