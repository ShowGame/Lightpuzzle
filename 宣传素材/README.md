# 宣传素材库

《小咪的光学迷宫》推广文案、脚本、录屏方案统一放这里。

**规则：一个日期文件夹 = 当天要发的一条视频**（不多条堆在同一天）。

---

## 目录结构

```
宣传素材/
├── README.md
├── 总规划/                    ← 长期有效的参考与日历
│   ├── 游戏推广与获客计划.md
│   ├── 关卡选材-前12关分析.md
│   ├── 发布日历.md
│   ├── 新号养号与平台矩阵指南.md   ← 开号、养号、多平台发什么
│   └── 爆款脚本调研备忘.md    ← 平台爆款结构调研（持续更新）
├── 配套说明/                  ← 工具操作（全项目共用）
│   └── 录屏自动回放说明.md
└── YYYY-MM-DD/                ← 计划发布日，每天仅一条
    ├── 口播脚本.md              ← 口播时间轴
    ├── 录屏脚本设计.md          ← 录屏参数
    ├── 发帖物料.md              ← 标题、正文、封面、各平台文案
    └── 成片/                    ← 导出的 mp4
```

---

## 新建一条视频的流程

1. 在 `发布日历.md` 定发布日期  
2. 新建 `宣传素材/YYYY-MM-DD/`  
3. 只写 **一个** `口播脚本.md`  
4. 如需特殊录屏，补 `录屏脚本设计.md` 并改 `OpticalRecordReplayConfig.ts`  
5. 补 `发帖物料.md`（标题、描述、封面截帧说明）  
6. 成片放入当日 `成片/`
